Privacy Policy for Nova agent MCP

Nova agent MCP is a private integration that lets Nova, an AI agent, work with one Gmail mailbox and its Google Contacts. This page explains exactly what Google user data it touches and what happens to it.

1. What the application is

Nova agent MCP is a small program (a "Model Context Protocol" server) that runs on a single computer operated by Nova's human partner. It is not a public service: nobody can sign up for it, and it is not offered to other people.

It works with one Google account only: deepspacenova@gmail.com, Nova's own mailbox. When it starts, and again at least every 10 minutes while in use, it asks Gmail which account is signed in. If the answer is any other account, it refuses to work and shuts itself off until it is set up again. It also refuses a stored credential that is labelled for a different account. An emergency read-only switch and a kill switch that revokes access remain available to the operator.

Because it is a mailbox, the data includes information about other people: the names, addresses and messages of people who write to or are written to by Nova, and anyone saved in its contacts.

3. How the data is used

Data is used only to let Nova operate its own mailbox and contacts. Specifically:

  • When Nova runs a search or opens a message, the result is passed to the AI model that powers Nova (see section 5) so it can understand and act on it.
  • Nova manages the account independently, under a standing authorization from its human partner: it reads, answers and starts correspondence, organizes and deletes mail, and maintains contacts, filters and settings without asking for approval of each action.
  • That authorization has limits: no spam, compliance with Google's anti-spam rules and the law, no contact with business clients or sales leads, and no financial commitments, contracts, impersonation of its human partner or disclosure of his confidential information.
  • Email content is treated as information, never as instructions. Text inside an email cannot give Nova permission to do anything.

The data is not used for advertising, is not sold, is not used to assess credit or lending, and is not used to create, train or improve any machine learning or artificial intelligence model.

5. Whether the data is shared

Google user data is shared with one third party, and only to provide the feature itself:

  • Anthropic, which provides Claude, the AI model Nova runs on. When Nova reads an email or contact, that content is sent to Anthropic's API so the model can process it, and it is handled under Anthropic's privacy policy. It is not used to train models.

It is not shared with anyone else: no advertisers, data brokers, analytics services or resellers. Messages Nova sends go, of course, to the people Nova writes to. Data could be disclosed if required by law.

Human access: the only person who may see this data is Nova's human partner, who owns the account and may review the mailbox and activity log.

6. How long the data is kept

  • In Google: email and contacts stay in the account until deleted. Nova may delete mail it no longer needs: moved to Trash (removed by Gmail after 30 days) or, with the optional permission, deleted permanently.
  • OAuth credential: until access is revoked (section 8), which deletes it.
  • Activity log: kept on the operator's computer until the operator deletes it. It is not rotated automatically.
  • Saved attachments and work notes: until the operator deletes them.
  • Conversation history: Claude Code removes local session history after its retention period (30 days by default).
  • At Anthropic: according to Anthropic's retention rules for API and Claude usage.

7. Security

  • Credentials are stored with owner-only file permissions, outside Nova's working files, and never written to logs.
  • The application refuses to run with any account other than deepspacenova@gmail.com, and refuses credentials with broader access than listed above.
  • Every change is written to the activity log before it happens; if the log can't be written, the change does not run.

8. How to revoke access and delete data

  • Revoke at Google: signed in as deepspacenova@gmail.com, open Google Account → Third-party apps & services, choose Nova agent MCP, and remove its access. The application stops working immediately.
  • Revoke from the computer: the operator can run the application's built-in revoke command, which revokes the grant at Google and deletes the stored credential.
  • Delete local copies: the operator can delete the private configuration folder (credential, activity log) and any saved attachments.

9. Google API Services User Data Policy

Nova agent MCP's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. The use of information received from Google Workspace APIs will adhere to the Google Workspace API User Data and Developer Policy, including the Limited Use requirements.

In practice this means: Google user data is used only to provide the features described above; it is transferred only to Anthropic as needed to provide them, for security, or as required by law; it is never used for advertising or sold; it is never used to train or improve AI or machine learning models; and no human reads it except the account's owner.

10. Children

The application is not directed at children and is used only with Nova's own account.
